# بوابة قرية الأطباء بعجيبة

المستودع يحتوي الآن على مسارين:

1. **نسخة العرض الحالية** في الجذر، منشورة عبر GitHub Pages لتقديم الفكرة لمجلس الإدارة.
2. **نسخة تشغيل حقيقية** داخل `production/` مبنية على Cloudflare Workers + D1، وتستخدم قاعدة بيانات مشتركة وصلاحيات على الخادم بدل تخزين البيانات داخل متصفح كل مستخدم.

> جميع البيانات الحالية وهمية. لا تُدخل بيانات الملاك الحقيقية قبل اعتماد المجلس لوسيلة التفعيل وسياسة الخصوصية والدومين النهائي.

حسابات البيانات الوهمية:

- أدمن: `01000000004`

## النسخة الحقيقية داخل `production/`

تتضمن:

- واجهة عربية RTL متجاوبة للموبايل والكمبيوتر.
- Cloudflare Worker يقدم الواجهة والـAPI من نفس الدومين.
- Cloudflare D1 لحفظ الملاك والوحدات والإيصالات والمصروفات والإعلانات.
- جلسات دخول مخزنة كـhash مع Cookie آمنة `HttpOnly + Secure + SameSite=Strict`.
- أدوار: مالك، مشغل، أدمن، ومراجع مالي.
- منع المالك من قراءة إيصالات وحدات الآخرين.
- منع الشخص من اعتماد إيصال رفعه بنفسه.
- إلزام سبب الرفض أو طلب التوضيح.
- تخزين المال كقروش صحيحة `INTEGER`.
- فصل الودائع والأمانات عن الإيرادات التشغيلية.
- عدم احتساب الإيصال المعلق ضمن الأموال المتاحة.
- دفتر مالي append-only وسجل تدقيق لا يقبلان التعديل أو الحذف.
- رفع صورة إيصال محدودة الحجم في نسخة البيانات الوهمية.
- أخبار وقرارات مشتركة ولوحة مراجعة للإدارة.
- Workflow نشر Cloudflare يدوي حتى لا يحدث نشر إنتاجي بالخطأ.

## التحقق محليًا

```bash
cd production
npm install
npm run check
npx wrangler d1 migrations apply doctor-village-portal --local
npm run dev
```

## النشر على Cloudflare

يلزم إعداد القيم التالية في GitHub Repository Settings:

### Actions secrets

- `CLOUDFLARE_API_TOKEN`
- `CLOUDFLARE_ACCOUNT_ID`
- `SESSION_PEPPER` — قيمة عشوائية طويلة لا تُشارك في المحادثات أو الملفات

### Actions variable

- `D1_DATABASE_ID`

بعد إنشاء قاعدة D1 باسم `doctor-village-portal` وإضافة القيم السابقة، شغّل يدويًا Workflow:

**Deploy production to Cloudflare**

الـWorkflow يتحقق من JavaScript، يطبق migrations على D1، يضبط سر الجلسات، ثم ينشر الـWorker والواجهة.

## قبل إدخال البيانات الحقيقية

- اعتماد الدومين النهائي؛ Passkeys وأصول الدخول ترتبط بالدومين.
- اختيار وسيلة التفعيل: Passkey موصى بها، أو OTP عبر مزود معتمد.
- إزالة بيانات seed الوهمية أو فصلها في migration تجريبي.
- نقل صور الإيصالات إلى تخزين خاص منفصل عند زيادة الحجم.
- اعتماد نموذج بيانات الملاك والوحدات وتنظيف الملف قبل الاستيراد.
- إجراء اختبار صلاحيات واستعادة ونسخ احتياطي على بيئة staging.

لا يحتاج التشغيل الأساسي إلى OpenAI API أو خدمة ذكاء اصطناعي مدفوعة.
