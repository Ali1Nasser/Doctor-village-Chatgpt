# بوابة قرية الأطباء بعجيبة

نسخة عرض تفاعلية عربية RTL مخصصة لعرض فكرة المشروع على مجلس الإدارة قبل إدخال بيانات الملاك الحقيقية.

> جميع الأسماء والأرقام والمبالغ الحالية وهمية، ولا ينبغي استخدامها كبيانات تشغيل فعلية.

## رابط التجربة

بعد اكتمال GitHub Pages:

`https://ali1nasser.github.io/Doctor-village-Chatgpt/`

حسابات العرض:

- مالك: `01000000001`
- أدمن: `01000000004`
- كود العرض لكليهما: `123456`

## ما يمكن تجربته الآن

- واجهة عربية RTL متجاوبة للموبايل والكمبيوتر
- لوحة المالك وحالة الوحدة
- رفع إيصال بخمس خطوات مع حفظ المسودة محليًا
- سجل الإيصالات وحالات الاعتماد
- لوحة شفافية مالية تفصل المتاح والودائع والمعلّق والمتأخرات
- أخبار وقرارات مجلس الإدارة
- خريطة مبسطة مستخلصة من تصور القرية المرفق
- لوحة إدارة تجريبية لمراجعة الإيصالات
- اعتماد أو رفض أو طلب توضيح مع سبب
- وضع ليلي وتكبير الخط
- بيانات العرض محفوظة محليًا داخل متصفح المستخدم فقط

## ملاحظات مهمة

هذه النسخة هي **Board Demo** وليست بعد نظام الإنتاج النهائي المتصل بقاعدة بيانات حقيقية. قبل التشغيل الفعلي يجب إضافة:

- Cloudflare Worker API
- قاعدة Cloudflare D1
- R2 خاص لصور الإيصالات
- تسجيل دخول حقيقي باستخدام Passkeys أو وسيلة تفعيل يعتمدها المجلس
- صلاحيات RBAC على الخادم
- سجل تدقيق غير قابل للتعديل
- نسخ احتياطي واستعادة واختبارات استمرارية
- استيراد بيانات الملاك بعد تنظيفها واعتمادها

لا يحتاج العرض الحالي إلى OpenAI API أو أي خدمة مدفوعة.
