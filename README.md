# بوابة قرية الأطباء بعجيبة

نسخة موحّدة ونظيفة من أفضل ما ورد في الحزم السابقة، مكوّنة من مسارين واضحين:

1. **Board Demo** داخل `site/` — واجهة عربية RTL تعمل مباشرة على GitHub Pages ببيانات وهمية، ليجربها مجلس الإدارة على الموبايل والكمبيوتر.
2. **Production Backend** داخل `worker/` و`migrations/` — Cloudflare Worker + D1 بدون مكتبات تشغيل خارجية، مع جلسات آمنة، CSRF، RBAC، تخزين خاص لصور الإيصالات، سجل تدقيق، وقيد مالي append-only.

> كل البيانات الحالية وهمية. لا يوجد اسم أو رقم أو مبلغ حقيقي داخل النسخة المنشورة.

## تجربة العرض

بعد نشر GitHub Pages، افتح رابط المشروع واستخدم أحد حسابات العرض الظاهرة في شاشة الدخول، أو:

- رقم المالك: `01000000001`
- رقم الأدمن: `01000000004`
- كود العرض: `123456`

تقدر تختبر:

- لوحة المالك وحالة الوحدة
- رفع إيصال بخمس خطوات وحفظه محليًا
- مراجعة الإيصالات كأدمن واعتماد/رفض/طلب توضيح
- الشفافية المالية وفصل المتاح عن الودائع والمعلّق والمتأخرات
- سجل المصروفات وفصل من أنشأ عن من اعتمد
- الملاك والوحدات واستيراد CSV المقترح
- الأخبار والقرارات المثبتة
- بلاغات الصيانة ومراحل التنفيذ
- خريطة القرية الأصلية مع تكبير
- الألبومات مع قواعد الخصوصية
- الوضع الليلي وتكبير الخط والعمل دون اتصال
- سجل التدقيق والنسخ الاحتياطي المحلي لبيانات العرض

## التحقق المحلي

لا توجد dependencies للمشروع الأساسي:

```bash
npm run verify
```

التحقق يشمل syntax لكل JavaScript واختبارات بنيوية للأصول، المال بالقروش، ضوابط الأمان، والسجل المالي append-only.

## تشغيل نسخة العرض محليًا

```bash
python3 -m http.server 8080 --directory site
```

ثم افتح `http://localhost:8080`.

## نشر الإنتاج على Cloudflare

1. أنشئ D1 باسم `doctor-village-portal`.
2. ضع `database_id` في `wrangler.toml`.
3. طبّق `migrations/0001_schema.sql` فقط على الإنتاج.
4. لا تطبق `0002_demo_seed.sql` على الإنتاج.
5. أضف `SESSION_PEPPER` كـ Worker secret.
6. أدخل سجل الملاك الحقيقي بعد اعتماد المجلس وتنظيفه.
7. اربط وسيلة التفعيل المعتمدة، ثم اختبر الدخول على هاتف حقيقي.
8. شغّل النشر اليدوي من Workflow: **Deploy production to Cloudflare**.

```bash
npx wrangler d1 migrations apply doctor-village-portal --remote
npx wrangler secret put SESSION_PEPPER
npx wrangler deploy
```

## قرارات أساسية

- رقم الموبايل وسيلة دخول، وليس المفتاح الدائم للمالك أو الوحدة.
- المال يُخزن كقروش صحيحة `INTEGER`.
- الوديعة التزام وليست إيرادًا.
- الإيصال المعلّق يساوي صفرًا في الحسابات حتى اعتماده.
- صور الإيصالات ليست عامة ولا تُعرض إلا لصاحبها أو موظف مخول.
- السجل المالي لا يُعدّل ولا يُحذف؛ التصحيح بقيد عكسي.
- لا يعتمد الشخص إيصالًا يخصه.
- البيانات الشخصية لا تظهر في شفافية الوحدات؛ يظهر كود الوحدة فقط.
- التشغيل الأساسي لا يحتاج OpenAI API ولا خدمة مدفوعة.
